# 稳定无优先级版

本目录以 `stable_confirm` 当前版本为基线，只取消颜色搬运顺序限制：

- `main.py`：主车程序，部署为主车 SD 卡的 `/sd/main.py`。
- `minimain.py`：从车程序，部署为从车 SD 卡的 `/sd/main.py`。

## 识别顺序

上电或收到 `AA 55 08 08` 后，ID1～ID5 全部立即开放：

- 不再要求先识别或搬运 ID2（红色）。
- 不再要求最后识别或搬运 ID1（蓝色）。
- 自动搜索继续按稳定版的世界距离规则选择最近有效目标。
- 主控 `0x03,id` 可以指定任意尚未完成的 ID。
- 已完成 ID 仍从普通搜索、颜色确认、目标保持和坐标输出中排除。
- 主车越过黄线时记录完成 ID；从车仍在 `0x01` 后的下一次
  `0x00/0x02` 提交完成 ID。
- `0x08` 清空全部完成状态后，五个 ID 再次同时开放。
- `0x06` 继续执行不受完成状态和顺序限制的全颜色障碍扫描。

## 保留的稳定参数

- 自动首次锁定置信度保持 `0.30`。
- 最多观察 `7` 个真实模型推理帧，命中 `5` 帧后锁定。
- 主控指定颜色继续使用稳定版已有的 `0.25`、`3/5` 放宽确认，
  并要求候选落实到主控指定的真实颜色 ID。
- LAB 动态颜色确认、固定曝光、黄线、回库和 UART 数据包逻辑均不变。
- 模型路径为 `/sd/80lite0.5R.tflite`，曝光从
  `/sd/color_thr.txt` 的 `exposure_us=` 读取。
