# OpenART 双车视觉系统

当前版本：**2026-07-13 比赛冻结版**

本仓库提供主车与从车的 OpenART Plus 单文件视觉程序。比赛版以提交 `d040b74` 的识别、通信和旧四点世界坐标映射为基线，完成运行时精简和帧率优化。后续 `v1.0.0` 逆透视、地面网格及世界坐标重写暂不用于比赛。

## 比赛入口

| 文件 | 设备职责 |
| --- | --- |
| `main.py` | 主车程序；目标识别、黄线检测、过线状态和世界坐标上报 |
| `minimain.py` | 从车程序；目标识别和世界坐标上报，不检测黄线 |

主车和从车均使用 OpenART Plus，串口固定为 `UART12`、`115200 bps`。部署时分别将对应文件作为设备启动脚本，不要互换主从程序。

## 比赛版行为

- 支持淡蓝沙包、红色沙包、网球、棕色泰迪熊和白色泰迪熊五类目标。
- 支持 RT1021 通过 `0x03` 命令锁定最终目标颜色。
- 支持搬运前 `0x06` 其他颜色扫描，并通过 `0xC7` 数据包返回结果。
- 主车负责黄线检测和位置状态；从车 UART 数据包的黄线、位置字段固定为 `0`。
- 主从均保留彩色目标调试框，颜色与目标类别对应。
- 支持从 `/sd/color_thr.txt` 加载五组 LAB 阈值和曝光参数；文件无效时使用代码内置值。
- 主车保留 8 秒看门狗和每 10 帧垃圾回收，降低长期运行卡死和堆碎片风险。

## 帧率精简

- 删除比赛时不可达的内置逆透视标定界面和动态矩阵求解。
- 将当前四点标定矩阵预计算为常量，保持原世界坐标结果。
- 目标候选和跟踪改为单遍选择，减少每帧列表与临时元组分配。
- 删除无效 FPS 计时、镜头校正分支、角度计算和重复 UART 字段写入。
- 从车完全删除黄线阈值扫描和过线状态机。

调试绘框会占用少量处理时间。比赛前应在两块 OpenART Plus 上分别确认实际帧率、识别阈值、曝光、串口数据和连续运行稳定性。

## UART 数据包

主从目标数据均为 16 字节：

| 字节 | 内容 |
| --- | --- |
| `0-1` | 帧头 `0xAA 0x55` |
| `2` | 颜色 ID，`0` 表示无目标 |
| `3-4` | 世界 X，毫米，`int16` 小端序 |
| `5-6` | 世界 Y，毫米，`int16` 小端序 |
| `7-8` | 目标像素宽度，`uint16` 小端序 |
| `9` | 黄线标志，仅主车有效 |
| `10` | 位置状态，仅主车有效 |
| `11-14` | 保留字段，当前为 `0` |
| `15` | `data[2:15]` 累加校验和 |
