# 2026-07-21 省赛最终实战版本

这是 OpenART 双车视觉系统在 2026-07-21 省赛结束后的正式留存版本。

## 实战结论

- `01_稳定版_ID2先_5中7` 和 `03_最激进_ID2先_ID1最后_3中5` 均实际上车使用。
- 主车与从车最终使用的模型文件名是 `80lite0.5SS.tflite`；模型权重不公开，也不包含在 Git 归档中。
- 场地实际固定曝光是 `880 us`，由 SD 卡根目录的 `color_thr.txt` 中
  `exposure_us=880` 提供。
- 四份实战脚本均引用 `/sd/80lite0.5SS.tflite` 和 `/sd/color_thr.txt`。
- 四份脚本使用相同固定白平衡 `(92.00, 64.00, 101.00)`。

## 文件来源与完整性

两个版本目录和场地配置来自最终实战目录 `比赛烧录_2026-07-21(1)`。
为保护未公开模型，Git 归档删除了模型权重，并相应更新本说明、忽略规则和校验清单；实战脚本与版本说明没有修改。

各版本自带的 `版本说明.md` 早于最后一次现场调整，其中提到的
`80lite0.5R.tflite` 已经过时。最终事实以实际脚本顶部的
`MODEL_PATH = '/sd/80lite0.5SS.tflite'` 和本说明为准。保留旧文字是为了保证
实战原件的字节与校验值不变。

01 稳定版主车脚本的回退曝光已是 `880`；其余三份脚本的回退值仍是 `400`。
实战运行时会优先读取随本存档保存的 `color_thr.txt`，因此实际曝光为
`880 us`。不要为了统一回退常量而修改本存档中的原始脚本。

公开归档文件的 SHA-256 记录在 `SHA256SUMS.txt`。Git 提交和注释标签共同
保存本说明与校验清单；清单不包含未公开模型。

## 烧录方式

1. 在 01 或 03 中选择一个版本，主车和从车必须选择同一编号。
2. 将 `主车_SD根目录/main.py` 复制为主车 SD 卡根目录的 `/sd/main.py`。
3. 将 `从车_SD根目录/main.py` 复制为从车 SD 卡根目录的 `/sd/main.py`。
4. 自行准备有权使用的兼容三分类模型，将其命名为 `80lite0.5SS.tflite`，再与本目录的 `color_thr.txt` 同时放到两块 SD 卡根目录。
5. 重新上电后确认日志显示模型从 `/sd/80lite0.5SS.tflite` 成功加载。

本存档用于记录实战脚本和配置，不再继续调参或合并其它候选版本。由于模型权重不公开，单独检出本目录不能完整复现实战识别结果。
